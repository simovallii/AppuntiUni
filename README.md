# AppuntiUni
Materiale scritto da me per l'università. principalmente codice. Il materiale potrebbe essere impreicso/incompleto. C++ Java e Kotlin sono i principali linguaggi presenti al momento. E' possibile prendere il codice per trarre spunto e fare degli esercizi, o per confrontare il vostro codice con il mio. il livello del codice scritto è da studente di primo e secondo anno di informatica. Il livello, di conseguenza, non sarà elevato ma in continuo miglioramento.
